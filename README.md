# CAB320 Assignment 2 - Machine Learning

Group repository for CAB320 Assignment 2.

## Setup Instructions

1. Download `small_flower_dataset.zip` from Canvas.
2. Unzip it into the root project folder.
3. Open `CAB320-Assignment2-Learning.ipynb`.
4. Run the notebook cells in order.

## Group Workflow

- `main` branch = stable working version.
- Each member should create their own branch for changes.
- Use pull requests before merging into `main`.
